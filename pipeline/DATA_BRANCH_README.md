# Mandi price data

Generated by `pipeline/publish.sh` on the `main` branch from the
data.gov.in dataset "Current Daily Price of Various Commodities from Various
Markets (Mandi)" (resource `9ef84268-d588-465a-a308-a864a43d0070`), published
under the Government Open Data License – India.

This branch is rewritten as a single commit on every run. Do not commit here.
The file format is described in `docs/data-format.md` on `main`.
